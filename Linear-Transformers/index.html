Linear Transformers Are Secretly Fast Weight Programmers

Created2026-08-12|Updated2026-08-12|Machine Learning
|Post Views:

Abstract

论文 Linear Transformers Are Secretly Fast Weight Programmers 重新解释了 Linear Transformer 的本质：线性化 self-attention 并不只是 softmax attention 的高效近似，它也可以被看成 1990s Fast Weight Programmer (FWP) 的现代形式。

FWP 的核心思想是：一个 slow network 通过梯度下降学会在推理过程中动态修改另一个 fast network 的权重。放到 linear attention 里，fast weight memory 就是不断累积的 key-value 外积矩阵。每个 token 都生成一条写入指令，把当前 value 和 key 的外积写进有限大小的 memory；查询时，用 query 从这个 memory 里读出对应 value。

这篇论文最重要的贡献有两个：

  • 从 associative memory 角度分析 linear attention 的容量限制；
  • 提出一种 delta rule 风格的更新规则，让模型不仅能写入新关联，也能修正旧关联。

除此之外，论文还提出了 DPFP (Deterministic Parameter-Free Projection)，一种确定性、无参数的 attention linearisation feature map，用来在不引入随机特征采样的情况下扩大 key/query 的点积空间维度。

Motivation

标准 Transformer 的 self-attention 对序列长度 LLL 的计算复杂度是 O(L2)O(L^2)O(L2)，KV memory 随长度线性增长。为了处理长上下文，Linear Transformer 试图把 attention 改写成线性复杂度形式。

softmax attention 可以写成：

yi=∑j=1ivjκ(kj,qi)∑j=1iκ(kj,qi)y_i = \frac{\sum_{j=1}^{i} v_j \kappa(k_j, q_i)} {\sum_{j=1}^{i} \kappa(k_j, q_i)} yi​=∑j=1i​κ(kj​,qi​)∑j=1i​vj​κ(kj​,qi​)​

其中 softmax kernel 为：

κ(k,q)=exp⁡(k⊤q)\kappa(k, q) = \exp(k^\top q) κ(k,q)=exp(k⊤q)

linear attention 的基本做法是用一个 feature map ϕ\phiϕ 近似 kernel：

κ(k,q)≈ϕ(k)⊤ϕ(q)\kappa(k, q) \approx \phi(k)^\top \phi(q) κ(k,q)≈ϕ(k)⊤ϕ(q)

于是分子可以被改写成：

∑j=1ivjϕ(kj)⊤ϕ(qi)=(∑j=1ivj⊗ϕ(kj))ϕ(qi)\sum_{j=1}^{i} v_j \phi(k_j)^\top \phi(q_i) = \left(\sum_{j=1}^{i} v_j \otimes \phi(k_j)\right)\phi(q_i) j=1∑i​vj​ϕ(kj​)⊤ϕ(qi​)=(j=1∑i​vj​⊗ϕ(kj​))ϕ(qi​)

这意味着历史上下文可以被压缩进一个固定大小的矩阵：

Wi=∑j=1ivj⊗ϕ(kj)W_i = \sum_{j=1}^{i} v_j \otimes \phi(k_j) Wi​=j=1∑i​vj​⊗ϕ(kj​)

也就是递推形式：

Wi=Wi−1+vi⊗ϕ(ki)W_i = W_{i-1} + v_i \otimes \phi(k_i) Wi​=Wi−1​+vi​⊗ϕ(ki​)

查询时：

yi=Wiϕ(qi)zi⋅ϕ(qi)y_i = \frac{W_i\phi(q_i)}{z_i \cdot \phi(q_i)} yi​=zi​⋅ϕ(qi​)Wi​ϕ(qi​)​

其中 zi=zi−1+ϕ(ki)z_i = z_{i-1} + \phi(k_i)zi​=zi−1​+ϕ(ki​) 用于归一化。

论文的关键观察是：这个 WiW_iWi​ 就是 fast weight memory。Linear Transformer 每一步都在用 key-value 外积编程这个 memory。

Fast Weight Programmer View

早期 Fast Weight Programmer 的形式可以写成：

Wi=σ(Wi−1+ai⊗bi)W_i = \sigma(W_{i-1} + a_i \otimes b_i) Wi​=σ(Wi−1​+ai​⊗bi​)

yi=Wixiy_i = W_i x_i yi​=Wi​xi​

其中 WiW_iWi​ 不是训练结束后固定的 slow weight，而是在处理输入序列时动态生成的 fast weight。slow network 负责产生 aia_iai​ 和 bib_ibi​，也就是每一步的 fast weight update instruction。

如果把 aia_iai​ 看成 value，把 bib_ibi​ 看成 key，那么 linear attention 的更新：

Wi=Wi−1+vi⊗ϕ(ki)W_i = W_{i-1} + v_i \otimes \phi(k_i) Wi​=Wi−1​+vi​⊗ϕ(ki​)

就和 FWP 的外积写入完全对应。

这个视角很有用，因为它让 linear attention 的问题从“如何近似 softmax”变成了“如何设计一个有限容量的可学习 associative memory”。一旦这样看，容量、干扰、覆盖、遗忘、更新旧知识这些问题都会自然浮现。

Capacity Limitation

Linear attention 把所有历史 key-value association 压进一个固定大小矩阵。为了从 memory 里准确读出某个 key 对应的 value，不同 key 在 ϕ\phiϕ 空间里最好彼此正交。否则查询一个 key 时，会同时激活其他 key，读出的就是多个 value 的线性组合。

如果 ϕ(k)\phi(k)ϕ(k) 所在的点积空间维度是 ddotd_{dot}ddot​，那么最多只能容纳约 ddotd_{dot}ddot​ 个互相正交的 key。也就是说，当需要存储的 association 数量超过 ddotd_{dot}ddot​ 时，linear attention 会进入 overcapacity regime，检索误差会不可避免地积累。

这和 full softmax attention 不同。标准 Transformer 会保留所有历史 key/value，存储随序列长度增长；linear attention 则把历史压缩到固定状态里，效率更高，但记忆容量有限。

论文用 synthetic retrieval task 验证了这一点：

  • Linear Attention 设定 dkey=ddot=64d_{key} = d_{dot} = 64dkey​=ddot​=64，大约在 60 个 association 后开始明显出错；
  • DPFP-1、DPFP-2、DPFP-3 的容量随 ddotd_{dot}ddot​ 增大而提升，对应上限约为 128、256、384；
  • softmax attention 由于保留完整历史，整体表现仍然最好。

Method

Delta Update Rule

标准 linear attention 的写入规则是纯加法：

Wi=Wi−1+vi⊗ϕ(ki)W_i = W_{i-1} + v_i \otimes \phi(k_i) Wi​=Wi−1​+vi​⊗ϕ(ki​)

这个规则的问题是：它只会不断添加新 association，却不会显式删除或替换旧 association。当同一个 key 后来对应了新的 value，旧 value 仍然残留在 memory 中，造成干扰。

论文提出的改进是：写入之前，先用当前 key 从 memory 里读出旧 value。

vˉi=Wi−1ϕ(ki)\bar{v}_i = W_{i-1}\phi(k_i) vˉi​=Wi−1​ϕ(ki​)

然后模型生成一个动态写入强度：

βi=σ(Wβxi)\beta_i = \sigma(W_\beta x_i) βi​=σ(Wβ​xi​)

新的目标 value 是旧 value 和输入 value 的插值：

vinew=βivi+(1−βi)vˉiv_i^{new} = \beta_i v_i + (1-\beta_i)\bar{v}_i vinew​=βi​vi​+(1−βi​)vˉi​

对应的 fast weight update 写成：

Wi=Wi−1+vinew⊗ϕ(ki)−vˉi⊗ϕ(ki)W_i = W_{i-1} + v_i^{new} \otimes \phi(k_i) - \bar{v}_i \otimes \phi(k_i) Wi​=Wi−1​+vinew​⊗ϕ(ki​)−vˉi​⊗ϕ(ki​)

化简后得到：

Wi=Wi−1+βi(vi−vˉi)⊗ϕ(ki)W_i = W_{i-1} + \beta_i (v_i - \bar{v}_i)\otimes \phi(k_i) Wi​=Wi−1​+βi​(vi​−vˉi​)⊗ϕ(ki​)

这个形式很像 error-correcting delta rule：模型不是盲目写入 viv_ivi​，而是写入当前预测 vˉi\bar{v}_ivˉi​ 和目标 viv_ivi​ 之间的误差。βi\beta_iβi​ 则相当于动态 learning rate，由模型根据当前输入自己决定。

Sum Normalisation

作者讨论了两种 normalisation：

  • attention normalisation：维护 zi=zi−1+ϕ(ki)z_i = z_{i-1} + \phi(k_i)zi​=zi−1​+ϕ(ki​)，类似 Katharopoulos et al. 的 linear attention；
  • sum normalisation：直接把 ϕ(k)\phi(k)ϕ(k) 和 ϕ(q)\phi(q)ϕ(q) 除以自身元素和，使其元素总和为 1。

论文认为对于 delta update rule，sum normalisation 更合适。直觉上，矩阵向量乘法可以看作对矩阵列向量的加权求和；如果 ϕ(k)\phi(k)ϕ(k) 的元素和为 1，那么写入和移除项的权重更平衡，不会随着序列长度持续膨胀。

实验中，WikiText-103 上所有 delta update 模型都使用 sum normalisation；额外 attention normalisation 反而会让 perplexity 变差。

DPFP

线性化 attention 的核心是选择 ϕ\phiϕ。论文比较了几类选择：

  • Katharopoulos Linear Attention 使用 ϕ(x)=ELU(x)+1\phi(x) = ELU(x) + 1ϕ(x)=ELU(x)+1，简单稳定，但不扩维，ddot=dkeyd_{dot}=d_{key}ddot​=dkey​；
  • Performer/FAVOR+ 使用随机特征近似 softmax kernel，可以扩维，但引入采样复杂度和输出方差；
  • DPFP 试图兼具两者优点：确定性、无参数、可扩维。

DPFP 的低维直觉是：把二维输入空间分成多个互不重叠的区域，使不同区域在投影后天然正交。例如对于 k∈R2k \in R^2k∈R2，可以构造：

ϕ1(k)=r(k1)r(k2)\phi_1(k) = r(k_1)r(k_2) ϕ1​(k)=r(k1​)r(k2​)

ϕ2(k)=r(−k1)r(k2)\phi_2(k) = r(-k_1)r(k_2) ϕ2​(k)=r(−k1​)r(k2​)

ϕ3(k)=r(k1)r(−k2)\phi_3(k) = r(k_1)r(-k_2) ϕ3​(k)=r(k1​)r(−k2​)

ϕ4(k)=r(−k1)r(−k2)\phi_4(k) = r(-k_1)r(-k_2) ϕ4​(k)=r(−k1​)r(−k2​)

其中 r(a)=max⁡(0,a)r(a)=\max(0,a)r(a)=max(0,a)。

推广到高维后，DPFP 使用正负 ReLU 拼接，并通过 shifted/rolled feature 的逐元素乘法构造二阶特征。超参数 ν\nuν 控制扩维程度：

ddot=2dkeyνd_{dot} = 2d_{key}\nu ddot​=2dkey​ν

Experiments

Synthetic Retrieval

论文设计了两个 synthetic retrieval setting。输入是一串随机采样的 key-value association，最后给出 query，模型需要返回该 query 对应的 value。

第一个 setting 用来测试容量。keys 和 values 不重复采样，序列长度等于 unique association 数量。结果支持容量分析：

  • Linear Attention 在 association 数量接近 64 时开始积累错误；
  • DPFP 的容量随 ν\nuν 增大而提升；
  • FAVOR+ 在该实验中没有达到零损失；
  • softmax attention 仍是最强 baseline，但在 500 个以上 keys 时也更难完全收敛。

第二个 setting 用来测试更新规则。keys 和 values 允许重复采样，同一个 key 可能多次被分配不同 value。正确答案是最后一次写入的 value。这要求模型能替换旧 association，而不是简单累积。

结果显示，作者提出的 delta update rule 明显优于：

  • 简单 sum update；
  • Schlag et al. 2021 的 fast weight update baseline；
  • 替换为 DPFP 但没有 sum normalisation 的变体。

这个实验直接说明：delta rule 的价值不只是缓解 overcapacity，也能提升有限 memory 中对旧关联的编辑能力。

Machine Translation

机器翻译实验使用 WMT14 English-German，模型为 Transformer big 设置，训练约 4 天，使用 3 块 V100 GPU。作者比较 Standard Transformer、Linear Transformer、Performer 和 DPFP。

主要 BLEU 结果如下：

Model Valid d=64 Valid d=256 Valid d=512 Test d=64 Test d=256 Test d=512
Standard Transformer 26.6 - - 27.7 - -
Linear Transformer 25.5 - - 26.8 - -
Performer 24.2 24.9 26.7 24.4 25.3 27.7
DPFP - 26.2 26.2 - 26.9 27.1

结论是：Performer 在随机特征数量足够大时可以接近标准 Transformer；DPFP 在较小 ddotd_{dot}ddot​ 下表现更好，提供了一个简单性和性能之间的折中。

Language Modelling

语言建模实验使用 WikiText-103。作者主要想验证 delta update rule 在真实长文本建模中的效果。

Table 2 的 perplexity 结果如下：

可以看到，delta update rule 对 Linear Transformer 和 Performer 都有稳定提升。作者把使用 delta update rule 的 Linear Transformer 称为 Delta Network。

这个结果说明：在 Delta Network 中，额外 attention normalisation 不是必要的，去掉绝对位置编码也更好。

Unlimited Context Setting

由于 linear attention 的 state size 固定，理论上可以一直处理任意长输入。论文进一步测试了不截断 context 的 WikiText-103 设置：训练时把 fast weight memory 从一个 segment carry 到下一个 segment，但反向传播仍限制在当前 segment 内。

结果如下：

Linear Transformer 89.8M 0.13M >260 >260
Delta Network 89.9M 0.13M 27.8 29.4
Transformer-XL 90.9M 0.13M 65.7 65.5
Transformer-XL 90.9M 1.05M 29.3 30.1
Transformer-XL 90.9M 2.10M 26.4 27.4
Transformer-XL 90.9M 6.29M 24.6 25.5

Delta Network 还没有超过大 memory 的 Transformer-XL，但在极小 state size 下表现很好。这说明它的优势更偏向 memory efficiency，而不是绝对 perplexity。

Discussion

我觉得这篇论文最有价值的地方是它给 linear attention 换了一个解释框架。

很多 linear attention 工作默认问题是：“如何高效近似 softmax attention？”这篇论文则说：可以把 linear attention 看成一个可学习的有限 associative memory。它每一步都执行一条由模型生成的写入指令，把 key-value association 编程进 fast weights。

这个视角的好处是，它让一些原本不太显眼的问题变得很清楚：

  • fixed-size memory 一定有容量上限；
  • key 不够正交就会产生 crosstalk；
  • 简单外积相加不擅长替换旧信息；
  • 一个好用的 linear attention 需要显式设计 memory update rule。

delta update rule 的直觉也很干净：先看 memory 当前已经记住了什么，再写入 correction。它不像简单 sum rule 那样盲目累加，也不像全局 decay 那样会影响无关 key。附录中作者还和 Peng et al. 的 gated update rule 做了形式比较：当 k3=k2k_3=k_2k3​=k2​ 时，Peng 的全局门控会同时衰减 k1k_1k1​ 的 value；而 delta update 只修正 k2k_2k2​ 对应的 association，不动正交的 k1k_1k1​。

DPFP 则是另一个实用取舍。它没有 FAVOR+ 的随机特征采样，也不像 ELU+1 那样完全不扩维。它通过确定性稀疏特征提升 projected space 的容量，对 synthetic retrieval 很有效；在 WMT14 上也给出不错的 BLEU。

不过，这篇论文也留下几个边界：

  • Delta Network 的绝对语言建模质量仍不如大 memory Transformer-XL；
  • synthetic retrieval 强调精确 key-value recall，但真实语言建模未必总是这种模式；
  • DPFP 是简单有效的 feature map，但并没有证明它是最优 softmax approximation；
  • 实验规模以 2021 年标准合理，但和今天的长上下文 LLM 规模还有距离。

Takeaways

  • Linear Transformer 可以被看作 Fast Weight Programmer；
  • linear attention 的 memory 是由 key-value 外积累积出的 fast weight matrix；
  • fixed-size associative memory 的容量受 ddotd_{dot}ddot​ 限制；
  • 简单 sum update 不擅长编辑旧 association；
  • delta update rule 写入的是 v−vˉv-\bar{v}v−vˉ，也就是对当前 memory prediction 的 correction；
  • sum normalisation 对 delta update 更稳定；
  • DPFP 用确定性、无参数、可扩维的 feature map 替代随机特征；
  • Delta Network 在 WikiText-103 上明显优于普通 Linear Transformer；
  • 这篇论文的核心价值是把 linear attention 从 kernel approximation 问题推进到 memory programming 问题。
